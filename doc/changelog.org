* Changelog

** 0.4 series
*** 0.4.0
- add popup workaround for older Firefox versions: Firefox before 149 requires a user action for opening a popup. If we detect that we can open a window instead. As this is potentially annoying there's a setting for that, and it is disabled per default.
- fix CSS: now all pages share the same CSS, and we also now support dark mode.
- add support for command keys. This makes sense with Firefox 147 onwards where users can remove or update keybindings: Unlike Chrome Firefox does not allow shadowing browser bindings via extension shortcuts. Command keys go via the popup logic: we show a popup with additional info, and while the popup is open key events are handled there.
- rewrite all prefix maps into configurable prefix bindings. The obvious entry point are the command keys - but we also support the legacy keypress handler to throw prefix maps the popup route. There's now a setting to enable that.
- add logic for showing changelogs on updates, with a setting to enable it. It's off per default to avoid annoying users.
- export defun/defvars from our toy lisp to JS namespace. This allows calling those functions with =lisp.fn= from JS.
- improve documentation.
- add matrix room [[https://matrix.to/#/#emacs-keybinding:wachter.fi][#emacs-keybinding:wachter.fi]]
